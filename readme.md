## Проекты

### Правовая система судебной практики
**Задача:** система для работы с судебной практикой — хранение и поиск материалов, структурирование правовых позиций.
**Что сделано:** спроектирована архитектура и реализована система; весь цикл — от постановки задачи и проектирования до кода и отладки — выполнен с помощью нескольких нейросетей.
**Технологии:** Python, базы данных, ИИ-агенты, Git.
**Статус:** в активной разработке.

### Telegram-бот для командной работы со списком задач
**Задача:** общий список задач для нескольких пользователей прямо в мессенджере.
**Что сделано:** бот с пошаговым диалогом добавления задач (FSM), общим списком для всех участников, экспортом задач в CSV и сохранением в базу — данные не теряются при перезапуске.
**Технологии:** Python, aiogram, SQLite, FSM.

### Telegram-бот «Мини-кошелёк путешественника»
**Задача:** вести бюджет поездки и считать расходы в двух валютах.
**Что сделано:** несколько путешествий на пользователя, автоматический расчёт стартового баланса, конвертация расходов по актуальному курсу, подтверждение операций инлайн-кнопками, история расходов, ручное изменение курса, предупреждение о выходе за бюджет.
**Технологии:** Python, pyTelegramBotAPI, SQLite, ExchangeRate-API, inline-меню.

### CLI ИИ-помощник
**Задача:** консольный доступ к языковым моделям с сохранением истории переписки.
**Что сделано:** выбор модели из списка, несколько чатов на пользователя, хранение истории в базе, приближённый подсчёт токенов для контроля лимита, определение поддержки режима рассуждений.
**Технологии:** Python, REST API (proxyapi.ru), SQLite, JSON.

### Приложение-планировщик с графическим интерфейсом
**Задача:** личное приложение для планирования задач и напоминаний.
**Что сделано:** окна со списком, канбан-доской, календарём и архивом; напоминания во всплывающих окнах, теги, проекты, настройки, повторяющиеся задачи, хранение данных в SQLite.
**Технологии:** Python, tkinter, sqlite3 (только стандартная библиотека).

### Погодное приложение + VK-бот
**Задача:** получать погоду по городу или координатам в консоли и в сообществе VK.
**Что сделано:** геокодирование названий городов, текущая погода, прогноз на 5 дней, качество воздуха; кэширование ответов, повторные попытки при сбоях сети, понятные сообщения об ошибках; общий «движок» погоды используется и консолью, и ботом.
**Технологии:** Python, OpenWeatherMap API, VK API (Long Poll), JSON, кэш.

### Бронирование в ресторане (PostgreSQL)
**Задача:** учёт клиентов, столиков и бронирований с проверкой доступности.
**Что сделано:** схема базы из трёх связанных таблиц, набор операций CRUD для каждой сущности, проверка доступности столика при создании брони (свободное время и вместимость), консольный интерфейс, скрипты создания схемы и демо-данных.
**Технологии:** Python, PostgreSQL, SQL, CLI.

### Конвертер валют и погодный CLI
**Задача:** практика работы с внешними API: получение данных по HTTP, разбор JSON, устойчивость к ошибкам.
**Что сделано:** конвертер валют с кэшем курсов на 24 часа и конвертацией сумм; погодный CLI с геокодированием, ретраями и обработкой сетевых ошибок без падения программы.
**Технологии:** Python, REST API, JSON, requests, файловый кэш.

### Генератор PDF-документов
**Задача:** формировать готовые PDF-документы по данным из таблиц и JSON.
**Что сделано:** шаблон документа и автоматическая генерация PDF из набора исходных записей.
**Технологии:** Python, HTML-шаблоны, генерация PDF.
